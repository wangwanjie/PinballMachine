## Pocket Pinball 1.0

首个公开分发版本 / First public build.

### 内容 / What's inside

- 竖屏街机弹珠玩法：投珠 → 锁倍率 → 拉弹簧 → 落入亮槽按倍率返还
  Portrait arcade play: insert → lock multiplier → pull the spring → land in a lit slot to win back at the multiplier
- 9 套机台皮肤、8 种背景音乐、8 种音效风格；部分皮肤同步更换主屏幕图标
  9 cabinet skins, 8 music themes, 8 sound styles; some skins also switch the Home Screen icon
- 每日弹珠重置（重置到 100 颗，普通 3 次 / 永久解锁 6 次）
  Daily marble resets (back to 100; 3 per day standard, 6 with Lifetime Unlock)
- 简体中文 / 繁體中文 / English

### 安装包 / Package

- `PocketPinball.ipa`（固定文件名，与 `PocketPinball_v1.0_1_adhoc.ipa` 内容相同 / same file under a stable name）
- iPhone，iOS 15.0+，arm64
- Ad Hoc 签名，只能直接安装在描述文件已登记 UDID 的设备上；描述文件有效期至 2027-04-05。其他设备可尝试 AltStore / Sideloadly 自行重签，不保证可用。
  Ad Hoc signed: installs directly only on devices registered in the provisioning profile, which expires on 2027-04-05. Other devices may try re-signing with AltStore or Sideloadly; not guaranteed.
- 此分发方式下应用内购买走 Apple 沙盒环境，无法真实付费。
  In-app purchases run in Apple's sandbox in this distribution and cannot take real payments.
